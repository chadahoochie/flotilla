# Storage Subsystem Overview

## Zero-Allocation Ring Buffer Architecture
The storage engine uses a pre-allocated circular ring buffer with a compile-time capacity $N$ that must be a power of two ($N = 2^k$).

## Key Characteristics
- **Bitwise Indexing**: Given a Raft `LogIndex(i)`, the internal slot is found using bitwise AND: `slot = (i - 1) & (CAPACITY - 1)`.
- **Compile-Time Verification**: Uses inline `const { assert!(N > 0 && (N & (N - 1)) == 0, "Capacity must be power of two") }`.
- **Watermark Compaction**: As entries are archived to durable storage, the prefix watermark is advanced. Any slot behind the watermark is recycled without moving memory.
- **Cacheline Alignment**: Log structures are padded and aligned (`#[repr(align(64))]`) to avoid false sharing on multicore hardware.
