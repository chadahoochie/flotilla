# Storage Subsystem Overview

## Zero-Allocation Ring Buffer Architecture
The storage engine uses a pre-allocated circular ring buffer in [`RingBufferLogStorage`](file:///home/chad/source/rust/flotilla/src/storage/ring_buffer_log_storage.rs) with a compile-time capacity $N$ that must be a power of two ($N = 2^k$).

## Key Characteristics
- **Bitwise Indexing**: Given a Raft [`LogIndex`](file:///home/chad/source/rust/flotilla/src/types/log_index.rs)`(i)`, the internal slot is found using bitwise AND: `slot = (i - 1) & (CAPACITY - 1)` via `compute_slot_index`.
- **Compile-Time Verification**: Uses inline `const { assert!(N > 0 && (N & (N - 1)) == 0, "Capacity must be power of two") }`.
- **Watermark Compaction**: As entries are archived to durable storage, the prefix watermark is advanced via `compact_prefix`. Any slot behind the watermark is recycled without moving memory.
- **Cacheline Alignment**: Log structures in [`LogSlot`](file:///home/chad/source/rust/flotilla/src/storage/log_slot.rs) are padded and aligned (`#[repr(align(64))]`) to avoid false sharing on multicore hardware.
- **Dedicated Error Handling**: Robust error semantics captured in [`StorageError`](file:///home/chad/source/rust/flotilla/src/storage/storage_error.rs).
