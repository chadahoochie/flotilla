# Consensus Subsystem Overview

## Sans-I/O Architecture
The consensus state machine in Flotilla is completely decoupled from OS timing primitives and network sockets. It provides two primary input methods:
1. `step(sender, packet_bytes)`: Process an inbound RPC packet envelope.
2. `tick()`: Advance the internal logical clock tick for election timeouts and heartbeat cadence.

Both methods yield an iterator or vector of outbound actions ([`OutboundMessage`](file:///home/chad/source/rust/flotilla/src/engine/outbound_message.rs): `SendPacket` or `ApplyEntries`) without blocking or making syscalls.

## Modular Public Decomposition
To adhere to the strict design rule of having **no private helper methods**, the consensus engine is split across dedicated public modules with each type in its own file:
- `election`:
  - [`ElectionState`](file:///home/chad/source/rust/flotilla/src/election/election_state.rs): Term progression, election timer, and vote tallying.
  - [`ElectionConfig`](file:///home/chad/source/rust/flotilla/src/election/election_config.rs): Node election timeout and heartbeat configuration.
  - [`ElectionAction`](file:///home/chad/source/rust/flotilla/src/election/election_action.rs): State transition actions (`Campaign`, `ElectedLeader`, `StepDown`).
  - [`rules.rs`](file:///home/chad/source/rust/flotilla/src/election/rules.rs): Standalone quorum and vote eligibility evaluation functions.
- `replication`:
  - [`PeerProgress`](file:///home/chad/source/rust/flotilla/src/replication/peer_progress.rs): Peer match/next log index tracking.
  - [`PeerProgressTracker`](file:///home/chad/source/rust/flotilla/src/replication/peer_progress_tracker.rs): Aggregated peer replication progress tracker.
  - [`FollowerAppendResult`](file:///home/chad/source/rust/flotilla/src/replication/follower_append_result.rs): Result enum for follower AppendEntries evaluation.
  - [`evaluator.rs`](file:///home/chad/source/rust/flotilla/src/replication/evaluator.rs): Log consistency and suffix truncation evaluator.
- `commit`:
  - [`commit.rs`](file:///home/chad/source/rust/flotilla/src/commit.rs): Quorum median calculations and commit advancement evaluation.
- `engine`:
  - [`RaftNode`](file:///home/chad/source/rust/flotilla/src/engine/raft_node.rs): Top-level composition type.
  - [`RaftConfig`](file:///home/chad/source/rust/flotilla/src/engine/raft_config.rs): Consensus node configuration parameters.
  - [`EngineError`](file:///home/chad/source/rust/flotilla/src/engine/engine_error.rs): Engine error enumeration.
  - [`OutboundMessage`](file:///home/chad/source/rust/flotilla/src/engine/outbound_message.rs): Emitted outbound actions.
  - [`packets.rs`](file:///home/chad/source/rust/flotilla/src/engine/packets.rs): Standalone packet constructors.
