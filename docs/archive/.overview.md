# Archive Subsystem Overview

## Archiving Architecture
The consensus core operates at microsecond latencies in DRAM. In order to store historical state durably and avoid running out of pre-allocated ring buffer slots, committed log entries are transferred across a lock-free or bounded ring channel to an asynchronous background worker.

## Components
1. `ArchiveQueue`: Pre-allocated bounded ring buffer between the Raft state machine and the background worker.
2. `AsyncArchiveSink`: Trait implemented by durable storage targets (`write_batch`, `flush`, `close`).
3. `ArchiveWatermark`: Monotonically advancing index acknowledging durable persistence, allowing the consensus core to advance `first_index`.
